# Cortex-M0 滚动道路游戏

EG4S20BG256，32 MHz Cortex-M0，240×320 竖屏，MADCTL=0x08。游戏、关卡、碰撞与绘制均由 M0 执行。当前包含 SD 卡关卡读取、选关、静态缺口、逐格踩踏玻璃动画、普通/短跳格、低矮障碍、完整阻挡、空中体和整格地面体及两种失败动画。Hills 原创路线与独立美术配置见 [HILLS.md](HILLS.md)。

## 操作

开机尝试读取 SD 卡根目录 RSLEVELS.BIN，然后进入选关页：KEY6 向左、KEY14 向右、KEY8 开始。右下绿色 SD 表示卡目录成功加载，白色 ROM 表示使用备用三关，红色 ROM 表示读取失败。菜单 KEY4 重新读卡；选择范围取自卡包目录（最多 24 关），没有成功读卡时为第 1～3 关（03 Hills）。首页不显示按键提示，顶部为固定居中的两行斜体 Rolling / SKY 标志，带深蓝投影、黄色球点缀及双色短横线，关卡以前后叠放卡片显示；两侧仅显示范围内的相邻关卡。蓝色背景静态填色，没有云或首页动画，仅在进入首页或选关/状态变化时重绘。实体已确认显示 SD，第三关可开始；细节见 SD_CARD.md。

游戏内：

- 按住 KEY6/KEY14：左右移动，松开停止，两键同时按下停止。横移 7.8125 格/秒，限制在第 1～5 列中心之间。
- KEY4：重开当前关卡，清空跳跃、失败动画和临时地图修改。
- KEY8：暂停/继续游戏及跳跃。失败后动画仍会播放完。
- KEY12：返回选关页，保留当前选择；开始关卡时重新初始化进度。普通地砖标记当前默认开启。
- 顶部红条：失败；绿条：通关。

道路前进 2.9296875 格/秒，整数累计 3/4 Q8 单位/ms，比上一版快 20%。球心通常在 (120,192)，直径 68 px，金色明暗，无花纹或地面阴影。

SD 文件格式、编辑工具、缓存和实体结果与格式见 [SD_CARD.md](SD_CARD.md)。现已准备四关 V3 包：第三关 1024 行，第四关为 288 行 Hills（约 1 分 37 秒）。

## 第一关与统一数据

`Level` 包含关卡长度、地面分段表和特殊对象表。地面分段和特殊对象都按世界行号升序排列。`GroundRun {first_row,row_count,ground_mask}` 用 5-bit 掩码描述地面，最低位为左列；未列出的关内行完整，终点之后无地面。`TileEvent {row,columns,kind}` 描述特殊格，当前类型为 `TILE_JUMP`、`TILE_LOW_BARRIER`、`TILE_FRAGILE`、`TILE_SOLID`、`TILE_AIR_BLOCK`、`TILE_SHORT_JUMP`、`TILE_GROUND_BLOCK`。对象按世界行号从小到大排列，供远近绘制。判定类型为跳跃触发、低矮障碍、脆弱地面、完整阻挡；美术配置不在地图中。选关通过只读 `levels[]` 注册表与 `LEVEL_COUNT` 枚举可选关卡，确认/重开统一调用 `level_load()`。备用三关不设解锁限制；卡上目录加载成功后选关数量来自文件头。

第一关 72 行，行号从 0 开始：

- 青色跳跃格：第 19/35/51 行，第 3/2/5 列（列从 1 开始）。
- 红色方块墙：第 21/37/53 行，横跨五列，位于完整道路上。
- 独立缺口：第 28～30、44～46、60～62 行，保留地面掩码 27、19、17。跳跃格与墙配合，缺口段需要换道。

保持默认中间位置可体验第一处自动跳墙；之后需换道通过缺口和进入下一跳跃格。缺口从最远可见处起就显示为空；已移除橙色收缩。前两关第 8 行新增横排玻璃，踩过后只给对应格播放下落，不改变普通地面支撑。

第二关 80 行，使用相同规则但改变路线：

- 跳跃格：第 15/31/47/63 行，第 5/1/4/2 列；墙在第 17/33/49/65 行，均横跨五列。
- 缺口：第 24～26、40～42、56～58、72～74 行，地面掩码 7、28、14、17。
- 第一块跳跃格在右侧第五列，需要在起步后先向右移动。

菜单数字用小型 5×7 字符表，英文标题使用 1124 B 的四色游程表，静态黄色球为 70 B 游程数据；背景与卡片均用色块绘制，没有全屏背景图片或帧缓冲。首页没有周期刷新。退回菜单和切换关卡后，跳跃、失败动画、相机和前进余量都会在开始时重置；游戏计时不会包含菜单停留时间。

## 跳跃、墙与失败

球心进入青色格后半格自动起跳，腾空 1536 ms，前进 4.5 格，整数抛物线最高抬升 81 px。空中可以横移。地面定位仍用固定 y=192 的投影深度，不能随画面球高度改变。

墙为单格宽、0.25 格厚、0.5 格高的方块拼成，亮顶面、暗侧面、红色正面表达厚度。球进入墙占据的行前 1/4 格、且列掩码重叠时，要求球心抬升至少 64 px（当前球半径和固定视角下的标定间隙），不足则撞墙。正确从前方跳跃格中部起跳时，在墙前达到足够高度。落地恢复地面支撑判断，同一跳跃格行锁存防重复触发。

踩空后世界前进与横移停止，球按 t² 加速向屏幕下方坠落；撞墙后球短暂向后反弹并闪红。两类动画持续约 800 ms，结束后球消失并保持失败状态，KEY4 重开。

## 绘制与资源

道路逐扫描线从远到近绘制，缓存 320 行深度/缩放，无运行时浮点。顶部 24 px/格、底部约 97.62 px/格，纵向约 13.07 格。球复用同一份单字节 RLE 数据，521 段、675 B 只读表，通过源行偏移表现跳跃与下落。

墙每帧整数投影并缓存至多 32 个四边形面，边斜率预计算；每行直接合成有序颜色区间，再合成道路和球。无全屏帧缓冲。旧关卡同屏至多一堵墙；剔除内部侧面后为 10 个可见面；自定义关卡应保持可见面数不超过 32。球在墙层之后合成，适用于当前碰撞停止和跳过低墙的玩法；尚未实现球在高墙背后的通用遮挡。

程序 BRAM 共 32 KiB（代码限 24.5 KiB，另 7.5 KiB 为 SD 美术缓存），数据 RAM 保持 8 KiB，栈顶 0x20002000；RTL 接口/存储器地址宽度、链接脚本和启动栈同步修改。SD 驱动版程序/静态数据见最新 VALIDATION.md（含墙面缓存及至多 67 个颜色区间）。最新综合和烧录记录见 VALIDATION.md。

LCD 每帧只设置一次 240×320 绘图窗口，依靠屏内地址自动递增连续输出各行；初始化清屏沿用同样的整屏写入方式。取消原来的每行地址窗口设置。无墙扫描线直接跳过墙面处理，不清空像素缓冲，不逐像素读取墙层；存在墙时按有序区间合成。游戏逻辑同一行的掩码只读取一次，仍按 1 ms 检查运动与碰撞。

每个正常道路帧仍写满 76800 个 LCD 像素，失败/通关提示条另写 960 像素。帧间最小 33 ms，若绘制更慢则按实际耗时推进。所有碰撞按 1 ms 小步检查，异常间隔最多推进 200 ms；不承诺实体帧率。

## 性能结果

32 MHz M0＋AHB＋LCD 整机仿真（含逻辑、墙投影及完整像素输出，不含帧间等待）：无墙由 59.07 ms 降至 29.19 ms，近墙由 72.91 ms 降至 34.12 ms；每帧仍为 76800 像素。旧版约 98% 耗时在绘制/LCD 输出，主要收益来自取消逐像素墙缓冲和每行绘图窗口。实际主循环仍以最小 33 ms 帧间隔调度；上述是仿真计时，实体帧率需板上确认。详细分项和构建/下载记录见 VALIDATION.md。

## 构建

`./build-fpga.ps1` 编译固件并执行 TD 综合、布局布线及 bitstream 生成。工程文件、构建脚本、引脚约束、时序约束和 PLL 源码在 `td/`；打开 `td/rolling_road.al` 即可查看工程。正常映像为 `firmware/code.hex`，生成的 bitstream 为 `td/rolling_road.bit`（生成物不纳入版本库）。SRAM 下载断电不保留。

仓库已包含 ARM DesignStart Cortex-M0 核心源文件 `rtl/cortexm0ds_logic.v`，供获许可的项目成员使用；所有使用和复制仍须符合适用的 ARM 许可协议。构建还需要 Anlogic TD 和 ARM Compiler 6。Windows PowerShell 中可通过环境变量 `ARMCLANG_BIN` 指向包含 `armclang.exe` 的目录，`TD_COMMANDS_PROMPT` 指向 `td_commands_prompt.exe`；未设置时脚本尝试原作者机器上的默认安装目录。TD 芯片数据库由软件安装提供。

本仓库按约定不上传仿真目录 `modelsim/` 和基准测试目录 `bench/`，因此这里保留的历史性能与仿真记录无法在仓库内重跑；需要相应仿真/基准源文件的协作者应从项目所有者处另行获取。正常下载使用非 Profile 固件，优化级别为 -O2。

原始课程 OrderTerminal 工程未修改。

美术包 RSART.BIN 与判定包分离；原背景及树模型从 SD 一次读入预留缓存，逐帧无需读美术文件。无卡时使用简单备用外观。详见 HILLS.md。

Hills 当前有 38 个设计关口和三段错列连跳，已加入短跳与分高度伤害体；判定/资源开销和未实现范围见 MECHANICS.md。
