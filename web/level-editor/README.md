# Rolling Sky 关卡工坊

[打开在线关卡工坊](https://rolling-sky-level-studio-ligan.elven-melon-1536.chatgpt.site)。在线版保持仅所有者可访问，需要使用对应账号登录。

离线网页编辑器，匹配当前 EG4S20 固件的 `RSLEVEL4` SD 关卡包。使用浏览器打开 `dist/index.html` 即可，无需安装依赖。也可在项目根目录执行下列命令后访问 `http://127.0.0.1:8766`。

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory web/level-editor/dist
```

## 操作

1. 初始目录保留项目现有 5 关，并添加一个 128 行的“我的第一关”。点击目录选择编辑对象。
2. 左侧工具可以拖到五轨道网格。点击工具后，按住鼠标划动可连续铺设。
3. 选择模式可以查看格子和修改机关参数，也可以拖动已有格子。移动会覆盖目标格，原位置变为空缺。
4. 右侧输入长度并应用。延长部分铺满普通地板，缩短会提示并裁剪超出部分。撤销可以恢复。
5. 导出 `RSLEVELS.BIN`，包含当前目录全部关卡。备份卡上同名文件后，将导出文件复制到 FAT32 SD 卡根目录，保留 `RSART.BIN`、视频等其他资源。
6. 安全弹出读卡器，开发板断电插卡后上电，菜单按 KEY4 重读。KEY6 / KEY14 选关，KEY8 开始。

支持 JSON 草稿与 V4 BIN 导入、关卡创建/复制/删除、撤销重做、网格缩放和跳转行号。Ctrl+S 保存 JSON，Ctrl+Z 撤销，Ctrl+Shift+Z 重做。JSON 可继续由项目的 `tools/make_sd_levels.py` 编译。

草稿使用 IndexedDB 自动保存在当前浏览器和来源下。离线地址、本地服务器地址与线上地址的草稿各自独立。JSON 文件适合迁移和长期备份。草稿尚未满足低墙间距限制时仍可保存和重新编辑。

## 板端约束

- 目录 1～24 关，每关 16～65,535 行，每行 5 轨。
- 稳定 ID 为唯一的 1～65,535。编辑名称保存在 JSON 中，二进制不携带名称，板端按目录顺序显示编号。
- 每关最多 32 颗钻石、32 个动态机关。支持普通/短跳板、玻璃、低墙、实体/空中/伤害障碍、激光、横移障碍、竖摆锤、滚轮、飞锤。
- 机关周期使用前进距离 Q8 单位，1024 对应 4 行。参数保留固件原始单位，可在检查器中编辑。
- 低墙行间距至少 16 行，与项目编译工具一致。绘图缓存超预算给出提示。
- 外观仍按 SD 卡 `RSART.BIN` 的稳定 ID 关联。新增 ID 使用现有固件的默认外观。
- 导入 BIN 支持当前 V4。历史版本可导入 JSON 源文件。导出的 JSON 保留地块、钻石和机关，原源文件的 route/gates 设计期注释不会继承到编辑稿。

## 验证

编辑、导入、撤销、重做或切换关卡后，右侧的「整关可达性」会自动重算。模拟从板端的出生位置开始，按 1 毫秒推进，包含跳板、落地支撑、障碍碰撞体和按距离变化的机关。找到走法表示在 33/33/34 毫秒的按键节奏下存在一条通关路径。只有允许每步自由横移后仍无路线时，才判定「确定堵死」。如果搜索达到上限，或无法可靠模拟特殊机关参数，会给出「未能确认」。点击定位按钮可查看对应行。通关判定允许跳过钻石，实机操作难度仍以试玩为准。

在项目根目录运行。

```powershell
node web/level-editor/tests/codec.test.cjs
node web/level-editor/tests/reachability.test.cjs
```

检查现有卡包逐字节一致、BIN/JSON 往返、最大长度/关卡数、边界参数与错误包，并用项目 Python 编译器复核二进制输出。浏览器交互验证结果记录在根目录 `VALIDATION.md`。
